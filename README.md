# Mohammad Anzar — Portfolio

Personal portfolio website for Mohammad Anzar, a Java Backend Developer & AI Integration Engineer based in Bengaluru, India.

🔗 **Live:** https://anzarmd.github.io/portfolio/

---

## Tech Stack

**Structure & Content**
- Vanilla HTML5 — semantic markup, Open Graph / Twitter Card meta tags, JSON-LD structured data (Person schema)

**Styling**
- Vanilla CSS3 — custom property token system (color, spacing, typography), CSS Grid & Flexbox layouts, scroll-reveal animations, responsive breakpoints, `prefers-reduced-motion` support
- Google Fonts — Oxanium (display), JetBrains Mono (code/monospace), Nunito Sans (body)

**Interactivity**
- Vanilla JavaScript (ES5-compatible) — IntersectionObserver-based scroll reveals and animated counters, cursor-tracking spotlight glow on cards (CSS custom properties + `pointermove`), 3D tilt with glare on the hero terminal, particle canvas background with a dot-grid, scroll progress bar, mobile hamburger navigation, smooth-scroll with nav offset, active nav-link detection, back-to-top button

**Contact Form**
- [EmailJS](https://www.emailjs.com/) — client-side email delivery without a backend server

**SEO & Social**
- Open Graph tags for rich link previews on LinkedIn, WhatsApp, Slack, Discord, iMessage
- Twitter/X `summary_large_image` card
- JSON-LD `Person` schema for Google rich results
- Canonical URL, `theme-color`, meta description, author and keywords
